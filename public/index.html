02 / Get started

From ZIP to first share.

01 — EXTRACT

Unpack the release

For Windows, keep arcminer.exe and its included DLLs together. Install a compatible NVIDIA driver.

02 — CONFIGURE

Set your wallet

Open a coin launcher such as rvn.bat and replace [WALLET ADDRESS] with your address for that coin.

03 — RUN

Mine when you choose

Launch the script to start foreground mining. Watch your connection and shares; press Ctrl+C to stop cleanly.

PowerShell / Windows example● ● ●
# Replace the wallet address before running
.\arcminer.exe --mine --coin rvn --pool stratum+tcp://stratum.ravenminer.com:3800 --wallet YOUR_RVN_ADDRESS --worker ArcWorker1

Transparent by design

A clear 1% developer fee.

Arcminer allocates 1% of active GPU hashing time to a separate developer pool account. It is a share of hashing time, not a deduction from your rewards.

The dashboard shows which account is active and the fee time. Your wallet and pool settings are explicit before you start mining.
